# Olist E-Commerce: Strategic Growth & Logistics Pipeline

## **Overview**
An end-to-end analytics solution transforming **100k+ Brazilian e-commerce records** into actionable business insights. This project bridges the gap between raw data engineering in **Snowflake** and executive storytelling in **Power BI**.

## **The Tech Stack**
* **Data Warehouse:** Snowflake (Cloud)
* **Transformation:** SQL (CTEs, DATEDIFF)
* **Business Intelligence:** Power BI (DAX, RFM Segmentation, Geospatial Heatmaps)

## **Key Insights**
* **Retention:** Identified that **92% of users are one-time buyers**, pinpointing a massive opportunity for loyalty-driven marketing.
* **Logistics:** Disproved the hypothesis that delivery delays were the primary driver of churn; delays were consistent across all customer segments.
* **Operations:** Highlighted regional bottlenecks in the Northwestern states via a custom **Geospatial Heatmap**.

## **Project Structure**
* `/sql_scripts`: DDL and Analytical View definitions.
* `/dashboard`: The final `.pbix` file.
* `README.md`: Project documentation and insights.

## **Data Source**
This project utilizes the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) on Kaggle. It contains 100k orders from 2016 to 2018.
